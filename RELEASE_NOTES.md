# ScoreBoard v0.1.0

First public release of ScoreBoard, an offline table tennis scoreboard for Android 8.0+.

- Track singles matches, service, and game times. Undo points, swap sides, or resume a match later.
- Customize the portrait and landscape scoreboard, set a timeout, and enable English or Russian announcements.
- Save match history locally, back it up as JSON, and share results as images.

Download `ScoreBoard-v0.1.0.apk` from **Assets** and open it on your phone. Android may ask you to allow installation from the app that opened the file.

## По-русски

Первый публичный выпуск ScoreBoard для Android 8.0 и новее. В приложении есть табло для одиночных матчей, таймеры, локальная история, русская и английская озвучка. Скачай `ScoreBoard-v0.1.0.apk` из раздела **Assets** и открой файл на телефоне.
